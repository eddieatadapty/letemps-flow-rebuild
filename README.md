# Le Temps Growth Audit

**Live → https://eddieatadapty.github.io/letemps-flow-rebuild/**

Five ideas to turn more Le Temps users into subscribers, each built into a clickable version of Le Temps's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what brought them on the first open, then lead with it | +10–15% CR to subscription |
| 02 | Make the wall sell Le Temps, not just the article | +5–15% CR to subscription |
| 03 | Show what CHF 29 a month buys, their themes first | +5–15% CR to subscription |
| 04 | Answer ✕ with your podcasts | +5–10% CR from offer closers |
| 05 | Ask for alerts on their themes, right after they subscribe | +10–20% notification opt-in |

Every price, rating and feature comes from Le Temps's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Le Temps. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
